# 2026-07-26 工作日志

## 修复：会员中心页面空白问题

**问题**：用户用 admin 账号登录后，点击"会员中心"页面内容为空。

**根因**：`index.html` 中 `membershipView` 和 `vocabView` 两个 `<div class="view">` 被放在了 `</main>` 标签**外面**（在 footer 和各种 modal 之后），而不是在 `<main class="main-content">` 内部。

- `<main>` 有 `min-height: calc(100vh - var(--header-height))`，即使内容为空也占满一屏
- 当 `navigateTo('membership')` 切换 view 时，`<main>` 内所有 view 被隐藏（`display:none`），`membershipView` 虽然获得 `active` class 变成 `display:block`，但它在 `<main>` 外部、footer 之后，被推到页面最底部
- 用户看到的是空白的 `<main>` 区域，实际会员内容在页面最下方需要滚动才能看到

**修复**：将 `membershipView` 和 `vocabView` 从 `</main>` 之后移到 `<main>` 内（`searchView` 之后、`</main>` 之前），与其他 view 放在一起。同时更新 CSS/JS 缓存版本号 `v=20260726d` → `v=20260726e`。

**验证**：admin 账号是 Pro 会员（active，到期 2027-07-25），后端 API `/api/tiers/` 和 `/api/membership/status/` 均正常返回数据。
